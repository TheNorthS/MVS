## Windows PowerShell 5.1 安装兼容修复

- 中文安装脚本改为带 BOM 的 UTF-8，避免 PowerShell 5.1 按 ANSI 误读后出现字符串未结束等解析错误。
- 安装 ZIP 打包时统一规范 `.ps1` 编码，不依赖构建操作系统或编辑器的默认设置。
- 增加源码与解压包在真实 Windows PowerShell 5.1 中的解析回归，以及 wheel/ZIP 哈希验证。
