# 本地路由微基准（历史记录）

本文对应 `examples/benchmark.py` 的确定性路由基准。新增 GPT 真实模型对照已单独实现，
运行方法见[模型实验说明](model_benchmark.md)，实测结果见
[GPT 240 组报告](../../artifacts/benchmarks/gpt-240-20261125-185218-v0.0.1/report.md)。下面关于“没有模型参与”的描述仅适用于旧微基准。

## 运行方式与测试对象

```sh
uv run python examples/benchmark.py
```

程序创建包含 20、50、100、200 个工具的真实进程内 MCPServer 实例，并通过官方 Client
发起协议调用。每个规模下，三种入口分别执行 20 次预定加法调用：直接 SDK 调用、最小
JSON 参数网关，以及包含权限、Schema 校验、审计和 SQLite 结果保存的完整 MVS 调用链。

## 测量口径

这里的 JSON 基线没有提供与 MVS 等价的权限、审计和结果存储能力。结果比较的是这些具体
实现，而不是单独的解析器开销。测试不包含模型推理、工具选择、启动过程或真实网络延迟。
中位数和第 95 百分位数（P95）是本地实测值，不代表生产环境性能保证。
原始结果保存在 [benchmark_results.json](../../artifacts/benchmarks/router/results.json)。

## 已记录结果与限制

记录中的 240 次预定调用全部成功。在该任务集下，MVS 比直接 SDK 调用耗时更多。
工具定义字节数不是模型词元（Token）数。由于没有调用模型，总 Token、模型选工具准确率
和模型任务成功率都为 `null`，表示未测量。

不能用这份微基准证明节省 Token。真实用量对比请查看独立的 GPT 实验，其方法、适用范围
和限制均单独说明。
