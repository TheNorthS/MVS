# 安全边界与部署限制

> 当前版本固定为0.0.1，包含加密存储、OAuth、审批、细粒度规则、资源约束和DNS绑定。
> 结合[生产能力说明](../guides/production_features.md)和
> [完成跟踪](../development/completion_tracker.md)区分已实现、已验证及仍未验收项目。

## 命令执行与权限

命令语言采用白名单解释器。进程启动有两个受控来源：官方 MCP stdio 传输，以及管理员
显式注册的原生命令后端。原生命令通过固定 executable/argv/cwd 和类型化参数绑定执行，
模型不能选择程序、工作目录、环境变量或整段动态执行源码。详情见[原生命令边界](../guides/native_commands.md)。
权限策略要求显式的服务器授权和工具白名单；工具注解不能授予权限。
排队后的调用会重新检查授权和注册表版本。受管后台为审批工具创建请求；批准绑定身份、参数
和工具版本，执行前一次性消费，未批准或重复使用会被拒绝。

## 身份、数据与审计

0.0.1安装实例提供受管理员Bearer令牌保护的管理API；普通工具执行令牌不能修改配置。
数据库保存访问令牌摘要，创建/轮换只回显一次。托管下游凭证使用Fernet加密，读取接口不回显。
同时拥有主密钥和数据库的主机管理员仍可解密，必须限制文件权限并安全保管主密钥。
浏览器令牌仅存内存，管理写入拒绝跨来源请求并校验Host。新增实例锁、版本冲突检查和
运行实例切换；可使用共享PostgreSQL控制状态与Redis会话，长期容错仍待验收。详见[管理接口](management_api.md)。

API 令牌映射到可信主体和租户，拒绝通过请求体注入身份。结果和会话访问同时检查租户与
所有者。审计不保留原始命令或参数值，并提供敏感字段的递归脱敏能力。
错误响应不包含原始传输异常文本、凭证或堆栈。描述、工具结果和资源内容都视为不可信数据；
不会自动执行返回内容中的命令。

## HTTP 与凭证

HTTP 连接要求管理员配置的主机名、DNS 解析后 IP 检查和 HTTPS。只有显式授权的数字
回环地址测试场景可使用 HTTP。每个发出的请求都检查同源约束，包括重定向后的请求。
私网地址必须由管理员明确允许。

HTTP MCP在套接字连接点使用通过检查的数字IP并保留Host/TLS SNI；其他模型和OAuth出站仍
依赖可信管理员配置。OAuth按用户管理凭证、支持续期与撤销；真实提供方仍需单独验收。
Bearer凭证可引用管理员环境变量或托管凭证，示例API仅监听本机。

## 存储与运行资源

SQLite 和对象文件存储面向单进程运行。Unix 目录权限为 `0700`，Windows 继承工作区
访问控制列表，部署者需要限制目录访问。共享模式提供PostgreSQL事务配额、Redis会话/限流、
S3对象内容和孤立对象修复，已完成功能验收；跨机器故障与长期压力仍需验证。

输入大小、递归深度和记录数有上限，但异步截止时间不能强制中断 Python 正则求值或同步
管道计算。`MVS_ISOLATED_VALIDATION=1`可启用带CPU/内存限制的校验与管道工作进程。
服务器也可能在返回值接受检查之前分配大量资源，因此不可信服务器进程需要操作系统或
容器级资源限制。当前实现不能作为通用资源沙箱。

## 兼容性测试边界

新增原生命令后端用 Windows Job 或 POSIX 进程组管理取消与超时后的进程清理；
单独的进程清理不提供文件系统/网络沙箱。Docker后端另行提供非root、禁止提权、只读挂载、
禁网络和cgroup资源限制；只在验收报告列明的环境中验证过。

SDK v1 的旧 API 导入只存在于隔离的 `tests/fixtures/` 夹具中，主项目运行时仍使用 v2。
缺少隔离夹具环境时，两项兼容测试会明确跳过；持续集成配置会安装该环境。
